<h1 align="center">Raghav Duggal's Portfolio</h1>

[![Site preview](/public/social-image.png)](https://raghav-d.vercel.app)

My engineering portfolio showcasing projects across enterprise security orchestration, codebase analysis, and machine-learning platforms. Built with [Remix](https://remix.run/), [Three.js](https://threejs.org/), and [Framer Motion](https://www.framer.com/motion/). View the [live site](https://raghav-d.vercel.app).

## Install & run

Make sure you have Node.js 19.9.0 or higher and npm installed. Install dependencies with:

`ash
npm install
`

Start up a local development server with:

`ash
npm run dev
`

## Deployment

This site is configured for zero-config deployment to [Vercel](https://vercel.com). Simply link your GitHub repository to Vercel and it will automatically build and deploy the application using the Edge-optimized Remix Vite compiler.

## Original Source

This portfolio was originally forked from the beautiful open-source portfolio designed by [Hamish Williams](https://github.com/HamishMW/portfolio). It has been extensively customized with new 3D WebGL scenes, interactive backgrounds, and content to fit my engineering background.
